# 線形MAFFTガイド木の検証

`--guide-tree=mafft-linear` を追加した。既定のビーム幅は200で、
`--guide-tree-beam=B` で正の整数を指定できる。
ガイド木の既定方式は引き続き厳密な `--guide-tree=mafft`。

MAFFT 7.526 nucleotide globalpair互換の置換スコア、affine gap、末端ギャップ規則、
距離の正規化、mixed linkageは厳密版と共通にした。確率モデルを置き換える方式ではない。
LinearAlignと同様の反対角線に沿ったビーム探索で、matchと2種類のgapを別々に枝刈りする。
スコアが同点でも各状態の上限Bを守る。配列対の向きを正規化し、左右交換で距離が変わらない。

各配列対で保持する状態の累計は最大 `3*B*(L1+L2)`。
3本の反対角線だけを保持し、全DP格子へのフォールバックは行わない。
時間は期待 `O(B*(L1+L2))`、作業メモリは `O(B+L1+L2)`。
選択に `nth_element` を使うため、Bへの依存まで含めた厳密な最悪時間の主張ではない。
配列数Nに対する全対距離と距離行列の二乗の部分は残る。

## Murlet dataset1

全85入力、各10配列の3,825組を照合した。厳密版の基準値は、先に
MAFFT 7.526本体と149入力で検証した内部実装の値。
以下の比較では小数点以下を丸めず、距離の一致判定許容差は `1e-12` とした。
木は左右の子の順序も含めて比較した。clade一致率は葉と全配列を除く部分集合の再現率。

| ビーム幅 | 木が完全一致した入力 | 距離が一致した配列対 | 平均clade一致率 | 最大距離差 |
|---|---:|---:|---:|---:|
| 100 | 83/85 | 3,812/3,825 | 0.997059 | 0.289650 |
| 200（既定） | 85/85 | 3,825/3,825 | 1.000000 | 0 |

幅200でも15入力では実際に枝刈りが発生した。全格子を計算した結果だけを比較したものではない。
幅100で木が変わったのは `RF00017-3`（入力参照のSRP_euk_arch）と
`RF00230-4`（T-box）。既定値は精度を優先して200とした。
入力ごとの値は [CSV](mafft-linear-guide-tree-murlet1.csv) に保存した。
ここでの結果はガイド木の照合であり、T=500の実行時間・RSSの再測定値ではない。
他のデータ、特に長い挿入や大きな長さの差がある配列でも同一になる保証はない。

## 自動テスト

300組の短いランダム配列について、枝刈りしない広いビームと厳密DPの一致を確認した。
狭いビームについては距離の対称性、厳密最適値との関係、同点での保持上限、候補数上限を確認した。
長さ5,000の同一配列でも状態数上限を確認した。
CLIはlinear/nonlinearの経路、alifold、単一配列、重複名、空入力、不正ビーム幅を検証する。

既存テストを含む22件が通過した。既存の `dd_recovery_pipeline` は、この変更前から
`benchmarks/dd_exact_diagnostic.py` が欠落してimportできないため除外した。
不正な数値などの引数解析エラーを終了コード0で返していた処理も修正した。

```sh
ctest --test-dir BUILD --output-on-failure -R '^guide_tree_(algorithms|pipeline)$'
```
